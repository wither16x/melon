Detailed Description

template<typename T>
requires std::is_trivially_constructible_v<T>
class Melon::Memory::Buffer< T >

Container for raw memory.

This container stores allocated raw memory and the size of the allocated area. Know that as you can see below, T must be trivially constructible.
